About MatchMind

Test Your Knowledge with MatchMind

MatchMind is a quiz application designed to make learning and testing your knowledge simple and fun. Users can choose different categories, difficulty levels and the number of questions before starting a quiz.

What Can You Do?

Choose a Category

Select from categories such as General Knowledge, Science & Nature, Computers, Mathematics and Sports.

Select Difficulty

Choose Easy, Medium or Hard questions depending on your knowledge level.

Choose Questions

Select how many questions you want to answer before starting the quiz.

Check Your Result

After completing the quiz, view your score, correct answers, wrong answers and skipped questions.

Question Sources

MatchMind supports two types of quiz questions. Users can choose the question source while customizing their quiz.

API Questions

Questions can be fetched from an online quiz API according to the selected category and difficulty.

Manual Questions

MatchMind also contains a collection of manually added questions organized by category and difficulty.

About the Project

MatchMind was developed as a web-based quiz application using HTML, CSS and JavaScript. The project focuses on creating a simple, interactive and user-friendly quiz experience.
